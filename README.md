# Web Developer Assessment

This project recreates the quiz-style layout from the supplied assessment reference.

## Run it
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Bootstrap is loaded from a CDN, so an internet connection is needed for Bootstrap styles.

## What to review before submitting
- Update the question wording if the recruiter provides the complete scenario.
- Check the page at desktop, tablet, and mobile widths.
- Make sure every image loads from the `assets` folder.
- Be ready to explain the CSS Grid, Flexbox, media queries, and JavaScript submit handler.

The supplied slide text does not fully explain the meaning of each image choice, so the image labels are descriptive rather than assumed answers.
